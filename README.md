## Expense Tracker — Трекер расходов

Веб-приложение для учёта личных финансов с визуализацией трат по категориям. Все данные хранятся в браузере локально — никаких серверов и регистраций. Быстро добавляйте расходы, следите за статистикой и анализируйте, куда уходят деньги.

## Стек

- **HTML5** — семантическая вёрстка формы и списка трат.
- **CSS3** — кастомные переменные, Grid, Flexbox, адаптивная вёрстка, плавные анимации, тёмная академическая тема (Dark Academia).
- **JavaScript (ES6+)** — работа с DOM, манипуляции с массивами, рендеринг, валидация форм, локализация (тенге, русский язык).
- **localStorage** — полное сохранение данных на устройстве пользователя.

Чистый ванильный стек, без фреймворков и библиотек.

## Как запустить локально

```bash
git clone https://github.com/ваш-аккаунт/expense-tracker.git
cd expense-tracker
start index.html
```

## Деплой
Вы можете залить папку с проектом на любой хостинг статики (GitHub Pages, Netlify, Vercel) — приложение будет работать полностью локально в браузере.

## Что работает
- Добавление траты — категория, сумма (в тенге), дата и необязательное описание.
- Категории расходов — Еда, Транспорт, Развлечения, Подписки, Прочее (каждая со своим цветом и иконкой).
- Итоговая статистика — общая сумма всех расходов и количество транзакций сверху.
- Визуализация по категориям — процентное соотношение от общих трат, прогресс-бары и суммы по категориям.
- История трат — список всех расходов, отсортированный от новых к старым. У каждого элемента есть кнопка удаления.
- Удаление всех трат — кнопка «Удалить все» с подтверждением.
- Локальное сохранение — все данные автоматически сохраняются в localStorage. После закрытия и повторного открытия браузера траты остаются на месте.
- Валидация формы — сумма не может быть пустой, нулевой или отрицательной; подсветка ошибки.
- Сброс формы — после добавления траты поля суммы и описания очищаются, дата сбрасывается на сегодня.
- Русскоязычный интерфейс — полная локализация на русский, форматирование дат (ДД.ММ.ГГГГ) и чисел (разделитель пробелами + ₸).
- Красивая тёмная тема — в стиле Dark Academia (шрифты Unbounded и Golos Text, мягкие акценты и прозрачности).
- Адаптивная вёрстка — на мобильных устройствах форма и блок категорий выстраиваются в колонку.

## Что не доделано
- Редактирование трат — пока можно только удалять и добавлять заново.
- Импорт/экспорт данных — нет кнопки для сохранения трат в файл или загрузки из файла (только ручной localStorage).
- Фильтрация по дате или категории — история показывает все траты сразу, нет поиска или фильтров.

## Что я узнал во время работы
- localStorage для хранения данных пользователя — научился сохранять и загружать массив объектов, обрабатывать ошибки парсинга и версионировать данные через ключ 'expense_tracker_v1'.
- Рендеринг динамических списков — отрисовка категорий с процентным соотношением, прогресс-бары через встроенные стили (width: ${barWidth}%).
- Escaping HTML — написал простую функцию escHtml, чтобы избежать XSS при выводе пользовательского описания.
- Работа с датами — форматирование ISO-строки в dd.mm.yyyy и установка значения по умолчанию для <input type="date">.
- Правильное форматирование чисел — использовал toLocaleString('ru-RU') для пробелов между разрядами и добавления символа тенге.
- Сортировка данных — перед рендером истории делаю копию массива и сортирую по id (новые записи имеют больший id, так как использован Date.now()).
- Анимации на CSS — плавное появление новой траты через @keyframes slideIn и переходы при наведении на кнопки.
- Структура проекта — научился разделять логику: index.html (разметка), style.css (внешний вид), app.js (всё приложение). Это оказалось удобнее для поддержки, чем монолитный файл.
